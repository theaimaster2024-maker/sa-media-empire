# Micvo

যেকোনো জায়গায় (Claude, Messenger, WhatsApp, Word) মাইকে বলে টেক্সট লিখে ফেলো — বাংলা বা ইংরেজি, যা বলবে তাই বসে যাবে। Gemini API দিয়ে চলে, নিজের ফ্রি key দিয়ে ইউজ করো, কোনো খরচ নেই।

Windows-এর জন্য, ব্যাকগ্রাউন্ডে চলে।

## ইউজ করবে কীভাবে

1. **Code → Download ZIP** চাপো
2. Zip-এর উপর **right-click → Extract All**, `C:\Micvo`-এ এক্সট্র্যাক্ট করো
   *(সরাসরি zip-এর ভেতর থেকে চালালে কাজ করবে না — Windows ওই ফোল্ডার মুছে দেয়)*
3. `C:\Micvo` ফোল্ডারে গিয়ে **SETUP.bat**-এ ডাবল ক্লিক করো
4. প্রথমবার একটা উইন্ডো আসবে — সেখানে Gemini API key চাইবে। উইন্ডোর ভেতরেই লিংক ও ধাপ দেওয়া আছে key নেওয়ার। বিনামূল্যে ২ মিনিটে হয়ে যায়
5. ব্যস। এখন যেকোনো টেক্সট বক্সে ক্লিক করে **Ctrl+Space ধরে রেখে বলো, ছেড়ে দাও** — লেখা বসে যাবে

শুধু এক টোকা দিলে টগল মোড চালু হয় (আবার Ctrl+Space চাপলে থামবে)। বাতিল করতে **Esc**।

PC restart দিলে নিজে থেকেই চালু হয়ে যাবে।

## Windows যদি ওয়ার্নিং দেখায়

"Windows protected your PC" — এটা স্বাভাবিক, কারণ এই অ্যাপে পেইড কোড-সাইনিং সার্টিফিকেট নেই। **More info → Run anyway** চাপলেই হবে। কোড সম্পূর্ণ ওপেন সোর্স, এই রিপোতেই সব দেখা যায়।

## API key নিয়ে

- key শুধু তোমার নিজের পিসিতে সেভ থাকে (`%APPDATA%\Micvo\config.json`), কোথাও পাঠানো হয় না
- Gemini-র ফ্রি টায়ারেই যথেষ্ট, স্বাভাবিক ব্যবহারে কোনো টাকা লাগে না
- মডেল: `gemini-3.1-flash-lite` (config.py-তে বদলানো যায়)

## অন্যান্য ফাইল

| ফাইল | কাজ |
|---|---|
| `STOP.bat` | এখনই বন্ধ করো |
| `REMOVE_AUTOSTART.bat` | PC চালু হলে আর নিজে থেকে চালু হবে না |
| `Micvo.bat` | সমস্যা হলে এভাবে চালাও, error দেখাবে |
| `config.py` | হটকি, ভাষার প্রম্পট ইত্যাদি বদলানোর জায়গা |

## নিজে কোড থেকে চালাতে চাইলে

```
pip install -r requirements.txt
python micvo.py
```

Python 3.10+ লাগবে।
